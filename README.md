# toastmasters-agenda-generator

[English](README.en.md)

クラブサポートシステム（tmcsupport.coresv.com）の例会詳細ページから、トーストマスターズの**例会プログラム（PDF）を自動で作る**ツールです。新宿バイリンガルトーストマスターズクラブのテンプレートに合わせて作っています。

これまで手作業で行っていた「システムの画面を見ながら役割を Excel に書き写して PDF にする」作業を、ボタン 1 つで済ませます。Google スプレッドシート上で動くので、**Mac でも Windows でも**、インストールなしで使えます。

## できること

- クラブ用の Google スプレッドシートのメニューから「① 次回のプログラムを作成」を選ぶだけで、次回の例会のプログラムができる
  - 役割・スピーチ・ゲスト・出欠をクラブサポートシステムから読み取る
  - JE（日本語セッションが先）/ EJ（英語セッションが先）を自動で判定
  - スピーチが 3 本の回は行を自動で追加
  - 「プロジェクト目標」ページに Pathways プロジェクトの説明文を記入
  - 入会式・ワークショップなどのイベントを、「イベント」シートに書いた位置と時間で追加
  - 終了予定が 21:15 を過ぎるときは、テーブルトピック・休憩・総合論評を自動で調整
- まず手直しできるスプレッドシートを作り、確認・修正してから「② 最新のプログラムを PDF 出力」で PDF にする（欠席などの変更にも対応しやすい）
- 必要なら、例会の当日に自動で作成する設定にもできる（初期状態はオフ）

## 必要なもの

- Google アカウント
- Web ブラウザ（Chrome、Safari、Edge など。OS は問いません）

## 使い方（プログラム担当の会員）

スクリーンショット付きの手順は [操作手順書](docs/manual/MANUAL.md) を見てください。

### プログラムを作る

1. クラブ用のスプレッドシートを開き、メニューの「**例会プログラム**」→「**① 次回のプログラムを作成**」を選ぶ
2. 「第○回例会のプログラムを作成します」と出たら「OK」
3. 「作成しました」の画面で「開く」を押すと、できあがったスプレッドシートが開く
4. 内容を確認し、必要なら直接書き直す
5. **テンプレートに戻り**、メニューの「**② 最新のプログラムを PDF 出力**」を選ぶ。最後に作成・手直ししたプログラムが PDF になり、同じフォルダに保存される（作成したプログラムを開いているときは、そのメニューの「このプログラムを PDF 出力」でも PDF にできます。ただしファイルごとに初回の承認が必要）

- 欠席などで変更が出たときは、スプレッドシートを直してから ② をやり直す（② は最後に更新したプログラムを PDF にする）か、① からやり直してください（① をやり直すと同じ名前のファイルがもう 1 つできるので、古い方は削除してください）。
- 「注意」としてプロジェクトの説明が見つからないと出た場合は、見出しだけが入っています。必要ならスプレッドシートに説明を貼り付けてください。
- 終了予定が 21:15 を過ぎるときは、テーブルトピック（各セッション 2 人まで）→ 休憩（最短 5 分）→ 総合論評（最短 5 分）→ テーブルトピック（各セッション 1 人まで）の順に自動で減らし、「注意」に表示します。減らしたテーブルトピックの行は非表示になっているだけなので、戻すときは行を再表示して C 列（所要時間）を 0:03 に戻してください。
- 次回以外の回を作るときは「① 回を指定して作成（mtgid）」を使います。mtgid は例会詳細ページの URL の `mtgid=` の後ろの数字です。

### イベントがある回（入会式・ワークショップなど）

① の前に、テンプレートの「**イベント**」シートに 1 行ずつ書きます。

| 例会回 | イベント名 | 挿入位置 | 所要時間（分） | 担当者 |
|---|---|---|---|---|
| 386 | 入会式 | 休憩の前 | 15 | （空欄なら例会ページから） |

- 挿入位置はプルダウンから選びます（会長挨拶・ゲスト紹介の後 / 前半スピーチの後 / 前半テーブルトピックの後 / 休憩の前 / 休憩の後 / 後半スピーチの後 / 後半テーブルトピックの後 / 表彰の前 / 閉会の前）。
- 担当者が空欄なら、例会ページの役割（「入会式担当」など）から入れます。
- 例会ページにイベントの役割があるのにシートに書いていない場合は、「注意」に表示されます。シートに書いてから ① をやり直してください。

### 初めて使うとき（1 回だけ）

最初にメニューを使うと「承認が必要です」と表示されます。次の順に進めてください。

1. 「続行」→ 自分の Google アカウントを選ぶ
2. 「Google はこのアプリを確認していません」と出たら、左下の「詳細」→「（安全ではないページ）に移動」
3. 「許可」

クラブで作ったスクリプトのため Google の審査を受けていないという表示で、問題はありません。許可する内容は「スプレッドシートとドライブのファイルの作成・編集」と「外部サービス（クラブサポートシステム）への接続」です。

### 定期実行（任意・初期状態はオフ）

メニューの「定期実行をオンにする」を選ぶと、**毎週木曜 13 時台**に、その日が例会日ならプログラムを自動で作成します。

- 例会の無い木曜は何もしません。すでに作成済みの場合も何もしません。
- PDF は自動では作りません。内容を確認してから ② を実行してください。
- オンにした人のアカウントで実行されます。オフにできるのもオンにした本人だけです。

## 初期設定（クラブ用アカウントで 1 回だけ）

クラブ用の Google アカウント（広報用・会場係用など）で行います。

1. **フォルダを作る**：クラブ用アカウントの Google ドライブに「例会プログラム」などのフォルダを作る。作成したプログラムと PDF は、ふつうはテンプレートと同じこのフォルダに保存される
2. **テンプレートを用意する**：このリポジトリの `template.xlsx` をダウンロードして 1 のフォルダにアップロードし、右クリック →「アプリで開く」→「Google スプレッドシート」→「ファイル」→「Google スプレッドシートとして保存」
3. **「設定」シートに入力する**：2 のスプレッドシートの「設定」シートに
   - B1：Zoom の URL・ID・パスコード（セルをダブルクリックしてから貼り付けると、複数行のまま 1 つのセルに入る）
   - B2：空欄のままでよい（テンプレートと同じフォルダに保存される）。別のフォルダに保存したいときだけ、そのフォルダの URL を入れる
4. **（任意）英語のプロジェクト説明を入れる**：日本語の説明はテンプレートに入っています。英語の説明も入れる場合は、下の「プロジェクト説明データ」の方法で「プロジェクト説明」シートを差し替える
5. **スクリプトを入れる**：「拡張機能」→「Apps Script」を開き、このリポジトリの [`dist/Code.gs`](dist/Code.gs) の内容をすべて貼り付けて保存。スプレッドシートを再読み込みすると「例会プログラム」メニューが出る
6. **共有する**：スプレッドシートと出力フォルダを、プログラム担当の会員に「編集者」として共有する（クラブの外には共有しない）

スクリプトを更新するときは、5 と同じ手順で `dist/Code.gs` を貼り直してください（作成済みのプログラムはそのままで大丈夫です）。

テンプレートの版と変更内容は、`template.xlsx` の「更新履歴」シートで確認できます。

以前のテンプレートを使っていて「イベント」シートが無い場合は、シートを追加して名前を `イベント` にし、1 行目に `例会回`、`イベント名`、`挿入位置`、`所要時間（分）`、`担当者` を入れてください（挿入位置の列はプルダウンにしておくと便利です。選択肢は上の「イベントがある回」を参照）。

### プロジェクト説明データ

「プロジェクト目標」ページに入る説明文は、「プロジェクト説明」シートから読みます。説明が無いプロジェクトは見出しだけが入ります。

- **日本語**：Base Camp の Resources で公開されている日本語版の資料から、目的・概要などを取り出したもの。**テンプレートに入っています。**
- **英語**：各プロジェクトの Evaluation Resource の Purpose。Evaluation Resource は会員が Base Camp にログインして見る資料なので、**このリポジトリには入れていません。** クラブ内だけで扱ってください。

英語も入ったデータは、次のどれかの方法で用意します。

- **A. 既存のクラブ用スプレッドシートからコピーする**（いちばん簡単）：英語入りのデータがあるスプレッドシートで「プロジェクト説明」シートのタブを右クリック →「別のワークブックにコピー」→ 新しいスプレッドシートを選ぶ。新しい側の元の「プロジェクト説明」シートを削除し、コピーしたシートの名前を `プロジェクト説明` に変える
- **B. クラブで保管している CSV を取り込む**：クラブの役員が保管している `project_descriptions.csv` を受け取り、「プロジェクト説明」シートを開いた状態で「ファイル」→「インポート」→「アップロード」→「現在のシートを置換」→「データをインポート」
- **C. 作り直す**（開発者向け）：`tools/build_projects.py` で CSV を作る。英語は、会員が Base Camp から Evaluation Resource の PDF を取得し、`cache/pathways/eval/{番号}.pdf` に置いてから実行する

## フォルダ構成

```
src/                  Google Apps Script のコード
dist/Code.gs          src/ を 1 つにまとめたもの（Apps Script に貼り付ける）
template.xlsx         プログラムのテンプレート（Google スプレッドシートに変換して使う）
tools/                開発用のツール（Code.gs の生成、プロジェクト説明データの生成）
docs/SPEC.md          詳しい仕様（記入ルール・セル対応表など）
tests/                テスト（tests/fixtures の HTML は氏名を架空のものに置換済み）
```

## 開発者向け

- 詳しい仕様は [docs/SPEC.md](docs/SPEC.md) にあります。AI コーディングアシスタント向けの指示は [CLAUDE.md](CLAUDE.md) です。
- テストと `dist/Code.gs` の生成には Node.js 18 以上が必要です（追加パッケージは不要）：

  ```
  npm test
  npm run build
  ```

- `src/` のファイルは Apps Script にそのまま貼れる形（`require` などを使わない、グローバル関数）で書いています。`src/dev.js` は開発用の関数で、メニューには出ません。
- プロジェクト説明データの CSV は `tools/build_projects.py`（Python + pymupdf）で作ります。出力先は `cache/pathways/`（リポジトリには含めない）。テンプレートの「プロジェクト説明」シート（日本語のみ）は `tools/fill_template_projects.ps1`（Windows + Excel）でこの CSV から更新します。
- テストに実際の例会ページを使うときは、氏名を架空のものに置き換えてから `tests/fixtures/` に入れてください。

## 注意事項

- 本ツールはクラブ会員が個人的に作成した非公式のツールです。Toastmasters International およびクラブサポートシステムの提供者とは関係ありません。
- クラブサポートシステムへのアクセスは 1 回の実行につき 3 リクエスト（ブラウザで例会ページを 1 回開くのと同程度）です。自動アクセスについてはシステムの運営者に許可をお願いしています。
