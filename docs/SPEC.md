# 仕様書：例会プログラム自動作成

新宿バイリンガルトーストマスターズクラブの例会プログラム（PDF）を、クラブサポートシステムの例会詳細ページから自動作成するための仕様です。AI コーディングアシスタントへの指示書としても使えるように書いています。

## 1. 背景

クラブは隔週で例会を開いています。これまでは、担当者がクラブサポートシステムのページを開き、役割の割り当てを Excel テンプレートに手で書き写し、PDF に印刷していました。この作業を自動化します。

- 利用者はプログラマーではない前提です。Mac・Windows どちらの会員も使えるよう、**Google スプレッドシート + Google Apps Script** で作ります。インストールは不要です。
- 例会詳細が確定するタイミング（スピーカーがプロジェクトとタイトルを入れた後）は毎回違うため、**手動実行が基本**です。定期実行（時間主導型トリガー）の機能も用意しますが、初期状態はオフで、必要なときにメニューからオンにします。
- 作成後に欠席などで変更が出ることがあるため、まず手直しできるスプレッドシートを作り、確認・修正してから PDF にします。

## 2. 動作環境

- Google アカウントと Web ブラウザ（OS は問わない）
- クラブ用の Google スプレッドシート（テンプレートとスクリプトを入れたもの）
- クラブ用スプレッドシートと出力フォルダは、クラブの Google アカウント（広報用・会場係用など）が所有し、プログラム作成を担当する会員に編集権限で共有する。アカウント自体は共有しない。スクリプトは実行した会員の権限で動き、各会員は初回のみ承認が必要。

## 3. データの取得元

### 3.1 クラブサポートシステム

- TOP：`https://tmcsupport.coresv.com/shinjukubilingualpha/`
- 例会詳細：`mtgDetail.php?mtgid=NNN`
- PHP のサーバー側で描画される HTML。ログイン不要。文字コードは UTF-8。

1 回の実行で送るリクエストは次の 3 つ（ブラウザで例会詳細ページを開いたときと同じ内容）：

| # | リクエスト | 用途 |
|---|---|---|
| 1 | `GET /shinjukubilingualpha/` | Upcoming 表から対象回の mtgid を決める |
| 2 | `GET mtgDetail.php?mtgid=NNN` | 基本情報・ゲスト・役割表・Upcoming |
| 3 | `POST mtgDetailGetMemberList.php`（`mtgid=NNN`、ヘッダー `X-Requested-With: XMLHttpRequest`） | 出欠表。ページ本体には含まれず、表示後に Ajax で読み込まれる |

> **robots.txt について**：サイトの robots.txt は 2026 年 4 月から全ページへの自動アクセスを `Disallow` としている。運営者に用途（自クラブのみ・隔週 1 回・数リクエスト）を説明して許可を依頼中。断られた場合やアクセスが遮断された場合は、自動取得をやめて「会員がブラウザで開いたページの内容を読み込む」方式に切り替える。遮断を回避する処理（User-Agent の偽装など）は行わない。

ページから取り出す項目：

| 項目 | 内容 |
|---|---|
| 基本情報 | 開催日（`2026/10/01` 形式）、回数（`第384回例会`）、会場（`角筈地域センター` / `四谷地域センター`）、会議室。会場と会議室は英語と日本語の 2 行で表示されるので日本語（最後の行）を使う |
| Guests | 1 行に 1 人。例：`山田さん（Area Director）`、`佐藤さん（キャンセル）` |
| 役割表 | Role / Name / Confirmation / Contents / Time / Award。Name 欄はプルダウンの選択値（`selected` の option）。`山田 太郎さん（ ○ ）` のように出欠マークが付くことがあるので、括弧部分は取り除く |
| スピーチの Contents 欄 | 左がプロジェクト情報、右がスピーチタイトル。左の形式は 2 種類あり、両方に対応する（下記） |
| 出欠表「Alphabetical Order あいうえお順」 | リクエスト 3 の応答。氏名 + 出欠マーク（`◎日本語` / `◎英語` / `◎日英` / `○` / `△` / `×` / 空欄）。末尾のダミー行「アサインなし さん」は除外 |
| Upcoming | 今後 5 回分の例会の日付・回数・リンク（`showDetail(NNN)` の NNN が mtgid）。例会詳細ページでは 2 列、TOP ページでは 5 列の表 |

スピーチのプロジェクト欄の形式：

- 旧形式（3 行）：`プレゼンテーション熟達` / `L3　知識を増やす` / `ボーカルバラエティについて`
- 新形式：`Presentation Mastery` / `L2:Introduction to Toastmasters Mentoring` / `（5分から7分）` / `🔗Project List & Materials List`（Pathways プロジェクト一覧へのリンク。URL の `range=A11` が一覧の行番号）

役割名（固定）：

- 日本語セッション：今夜のトーストマスター、今夜の言葉（日英）、計時係、集計係、文法係、えーとカウンター、笑いカウンター、例会報告係、準備スピーチ1〜3、テーブルトピックスマスター、テーブルトピックス回答者1〜4、総合論評、論評1〜2
- 英語セッション：Toastmaster of the Evening、Prepared Speech1〜3、Table Topics Master、Table Topics Speaker1〜4、General Evaluation、Evaluation1〜3
- ヘルパー役（計時係など）と今夜の言葉は例会全体で 1 組だけで、両セッション共通。
- 英語セッションの担当者も、画面表示（プルダウンの選択値）の日本語名を使う。隠し項目にあるローマ字名は使わない。

**JE / EJ の判定**：役割表の先頭行が「今夜のトーストマスター」なら JE（日本語セッションが先）、「Toastmaster of the Evening」なら EJ。

**対象回の判定**：Upcoming 表から「日付が今日以降」の最初の回。テスト用に mtgid の直接指定もできるようにする。

### 3.2 Pathways プロジェクト一覧（Google スプレッドシート、公開）

- `https://docs.google.com/spreadsheets/d/1ku8Aspg64CnHnyuFV3JD-d_3APnX56VxT_Z2pM3OEMw/edit?gid=827204203`
- 主な列：A = プロジェクト番号、B = Level、C = 英語プロジェクト名、D = 日本語プロジェクト名。「説明資料(英)」「説明資料(日)」列はプロジェクト説明 PDF（Google Drive、公開）。
- ここからプロジェクト説明データ（プロジェクト名 → `{code, level, name_ja, name_en, desc_ja, desc_en}`）を作る。desc は説明 PDF の冒頭の説明文（Purpose / Overview / This project includes の部分）。
- 開発者が `tools/build_projects.py`（Python + pymupdf）で生成し、`src/projects.js`（`PROJECTS`）としてスクリプトに同梱する。毎回の実行には含めない。一覧が更新されたら再実行する。
- 説明資料の PDF のうち、Google ドライブで共有が限定されているものは取得できない（2026-10 時点で英語版の多くが該当）。説明が無いプロジェクトは見出しのみ記入し、警告を出す。PDF を手元に置けば（`cache/pathways/pdf/{番号}_{en|ja}.pdf`）ツールはそれを使う。
- スピーチが日本語セッションでもプロジェクト名が英語で登録されていることがあるので、日英どちらの名前でも引けるようにする。新形式のリンクにある行番号でも引けるようにする。

## 4. テンプレート

元は `template.xlsx`（シート JE、EJ、プロジェクト目標）。これを Google スプレッドシートに変換して使う。JE と EJ は日英の順序が逆なだけで、セル番地は同じ。

- 印刷設定：A4 縦、1 ページに収める。印刷範囲は JE / EJ が `A1:O95`、プロジェクト目標が `B2:C8`。
- PDF には、その回で使うセッションのシート（JE か EJ）とプロジェクト目標を含める。
- B 列は開始時刻。`=上の行のB+上の行のC` の連鎖（B5、B7 は固定値）。**B 列は変更しない。**
- C 列は所要時間（時刻値）。

「前半」「後半」はセッションの順番を指す。JE なら前半が日本語、EJ なら前半が英語。

## 5. 記入ルール

### 5.1 ヘッダー

- 回数：`第384回`
- 日時：`10/01 19:15～21:15`（月日は 2 桁）
- 場所：Zoom 情報（URL・ID・パスコード。クラブ用スプレッドシートの設定に保存し、リポジトリには含めない）に続けて、会場行を入れる。
  - 形式：`会場：{会場の表記} {ページの会議室名}` + 改行 + 地図 URL
  - 角筈地域センター → `会場：角筈地域センター7F 会議室A` / `https://tsunohazucc.com/tsunohazu_map.html`
  - 四谷地域センター → `会場：四谷地域センター 集会室３` / `http://ycc.tokyo/about.html`
  - 未登録の会場は地図 URL なしで記入し、警告を出す

### 5.2 役割

- Assignment 欄（TMOE、ヘルパー、スピーカー、論評、TT マスター、総合論評）は**「さん」を付けない**。氏名はページの表記どおり（姓名間の空白も残す）。
- 前半の TMOE は J10、後半の TMOE は後半セッション見出し行の J43 に `TMOE: 氏名`。
- 今夜の言葉：担当者名のみ記入。括弧内の言葉は空欄（当日発表）。
- テーブルトピックス回答者は記入しない（当日指名）。
- ページで空欄の役割はプログラムでも空欄のまま。エラーにしない。

### 5.3 スピーチ

- 日本語タイトル：`『題目』（5～7分）`、英語タイトル：`"Title" (5-7 min)`。
- 時限：Contents 欄に `（4分から6分）` などがあればそれを使う（日本語は `（4～6分）`、英語は `(4-6 min)`）。なければ 5〜7 分。
- プロジェクト行：`パス名 Lx：プロジェクト名`（レベル名は書かない）。日本語は全角コロン `プレゼンテーション熟達 L3：ボーカルバラエティについて`、英語は `Motivational Strategies L3: Researching and Presenting`。
- プロジェクト目標シート：プロジェクト説明データを引き、見出し `L3: プロジェクト名` と説明文（日本語スピーチは desc_ja、英語は desc_en）を記入。見つからなければ見出しのみ記入し、ログに警告。同じプロジェクトが複数ある場合は 1 回だけ載せる。並び順はプログラムに出てくる順。使わない枠（見出し行と説明行）は行ごと非表示にして印刷しない。4 件以上ある場合は枠を追加する。

### 5.4 C 列の所要時間

- スピーチ：スピーカーがいれば「時限の上限 + 1 分」（5〜7 分 → 0:08、4〜6 分 → 0:07）。いなければ 0:00。
- コメントタイム：スピーカーがいれば 0:01、いなければ 0:00。
- 論評：担当者がいれば 0:05、いなければ 0:00。
- テンプレートで空欄のセル（C37 など）でも、担当者がいなければ 0:00 を記入する（「0:00」と表示される）。
- 上記以外の行はテンプレートの値のまま。

### 5.5 スピーチが 3 本の回

1 セッションに 3 本目のスピーチがある場合（年に 2〜3 回）、2 本目のブロックの後に同じ構造のブロック（見出し行 + タイトル行 + プロジェクト行 + コメントタイム行）を挿入し、論評にも 3 行目を挿入する。挿入した行には複写元の議事欄（A〜M 列）の書式・数式・見出しをコピーし、見出しの番号は 3 にする（`準備スピーチ 3`、`論評 3` など）。右側のゲスト・会員欄（N・O 列）はコピーしない。B 列は挿入した行とその次の行の数式をつなぎ直し、開始時刻の連鎖を切らない。**行の挿入を先に行い、右欄はその後に上から詰めて記入する**。

- 挿入位置（テンプレートの行番号）：前半はスピーチ 2 のブロック（25〜28 行）の後に 4 行、論評 2（37 行）の後に 1 行。後半は 49〜52 行の後に 4 行、論評 2（61 行）の後に 1 行。
- 日本語セッションには「論評3」の役割が無いので、論評 3 の行は担当者欄が空欄（0:00）になる。
- `buildFillPlan` が挿入の指示（`inserts`：挿入後の行番号）を返し、記入先のセル番地も挿入後の番号で返す。

### 5.6 右側の欄

- ゲスト：Guests 表の 1 行につき 1 人。（キャンセル）を含む行は除外。表記はページどおり（さんと括弧書きを含む）。
- 出席予定会員：あいうえお順の表で ◎（言語を問わない）または ○ の人。△・×・空欄は含めない。ページの順で、さん付き、氏名は表記どおり。
- □ は記入した行にだけ付ける（足りなければ追加し、余った □ は消す）。

### 5.7 今後の予定

Upcoming 表の、対象回を除いた最初の 2 件。形式は `11/05　木曜日　第386回例会`（曜日は日付から計算、会場は書かない）。

### 5.8 出力

メニューは 2 段階：

1. **① プログラム作成**：最新のページを取得し、クラブ用スプレッドシートのコピーを出力フォルダに作って記入する。名前は `新宿BTMC第386回例会プログラム20261105`。使わないセッションのシートは非表示。作成後にそのスプレッドシートを開く。
2. **② PDF 出力**：①で作ったスプレッドシート（手直し後）で実行し、表示中のシートを `新宿BTMC第386回例会プログラム20261105.pdf` として同じフォルダに保存する。コピーにも同じスクリプトが入っているので、そのまま実行できる。

変更があったときは、スプレッドシートを直接直すか、①をやり直す。Excel ファイルは作らない。

メニュー「例会プログラム」の項目：

- `① 次回のプログラムを作成`：TOP ページの Upcoming 表で、日付が今日（日本時間）以降の最初の回。確認ダイアログを出してから作る
- `① 回を指定して作成（mtgid）`
- `② PDF 出力`
- `定期実行をオンにする` / `定期実行をオフにする`

定期実行（初期状態はオフ）：

- 例会は毎月第 1・第 3 木曜。時間主導型トリガーで **毎週木曜 13 時台**（Asia/Tokyo）に実行する（Apps Script の仕様で、指定した時刻から 1 時間以内のどこかで動く）。
- Upcoming 表に**今日の日付の回がある日だけ** ① を行う（第 1・第 3 木曜の計算はしない。日程変更にもそのまま対応する）。出力フォルダに同名のファイルがあれば何もしない。PDF は作らない。
- トリガーはオンにした人のアカウントに作られ、その人の権限で動く。オフにできるのも本人のみ。

## 6. 構成

| ファイル | 役割 |
|---|---|
| `src/html.js` | 小さな HTML パーサー（Apps Script には DOM が無いため） |
| `src/parse.js` | HTML → meeting オブジェクト。`parseMeeting(pageHtml, membersHtml, mtgid)` |
| `src/fill.js` | meeting → 記入内容の一覧（`buildFillPlan`：セル番地と値、`objectiveLayout`：プロジェクト目標の記入と非表示行）。純粋な関数 |
| `src/main.js` | Apps Script 側：取得（UrlFetchApp）、スプレッドシートのコピーへの記入、PDF 出力、メニュー、定期実行 |
| `src/dev.js` | 開発用の確認関数（メニューには出さない） |
| `dist/Code.gs` | `npm run build` で `src/` をまとめたもの。Apps Script に貼り付ける |
| `src/projects.js` | プロジェクト説明データ（`tools/build_projects.py` で生成） |
| `tests/` | Node のテスト（`npm test`）と匿名化済みフィクスチャ |

メール送信は今回は対象外（後から追加できるようにしておく）。

### meeting オブジェクトの形式

```json
{
  "mtgid": 257, "date": "2026/10/01", "number": 384,
  "venue": "四谷地域センター", "room": "集会室３", "format": "JE",
  "guests": ["林さん（Area Director）"],
  "roles": { "今夜のトーストマスター": "青木 一郎", "論評2": "" },
  "speeches": {
    "ja": [{ "slot": 1, "speaker": "久保さくら", "path": "プレゼンテーション熟達",
             "level": "L3", "level_name": "知識を増やす", "project": "ボーカルバラエティについて",
             "time_limit": null, "project_row": null, "title": "…" }],
    "en": []
  },
  "attendance": [{ "name": "江口次郎さん", "mark": "○" }],
  "upcoming": [{ "date": "2026/11/05", "number": 386, "mtgid": 259 }]
}
```

- roles の氏名は「さん」なし、attendance の氏名は「さん」付き。
- キャンセルのゲストも guests に残し、除外は記入時に行う。
- `time_limit` は `{ "min": 4, "max": 6 }` または `null`。`project_row` は新形式のリンクにある一覧の行番号、無ければ `null`。
