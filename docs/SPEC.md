# 仕様書：例会プログラム自動作成

新宿バイリンガルトーストマスターズクラブの例会プログラム（Excel / PDF）を、クラブサポートシステムの例会詳細ページから自動作成するための仕様です。AI コーディングアシスタントへの指示書としても使えるように書いています。

## 1. 背景

クラブは隔週で例会を開いています。これまでは、担当者がクラブサポートシステムのページを開き、役割の割り当てを Excel テンプレートに手で書き写し、PDF に印刷していました。この作業を自動化します。

- プログラムは利用者本人の PC の Chrome でページを開きます（会員がブラウザで見るのと同じ）。1 回の実行で開くページは 2 つだけです。
- 利用者はプログラマーではない前提です。ダブルクリックで動く `run.bat` と、一般向けの README を用意します。

## 2. 動作環境

- Windows 10 / 11
- Microsoft Excel（デスクトップ版）
- Google Chrome
- 追加インストールは不要（Windows 標準の PowerShell 5.1 で動作）

## 3. データの取得元

### 3.1 クラブサポートシステム

- TOP：`https://tmcsupport.coresv.com/shinjukubilingualpha/`
- 例会詳細：`mtgDetail.php?mtgid=NNN`
- PHP のサーバー側で描画される HTML の表。ログイン不要。

ページから取り出す項目：

| 項目 | 内容 |
|---|---|
| 基本情報 | 開催日（`2026/10/01` 形式）、回数（`第384回例会`）、会場（`角筈地域センター` / `四谷地域センター`）、会議室。会場と会議室は英語と日本語の 2 行で表示されるので日本語（最後の行）を使う |
| Guests | 1 行に 1 人。例：`山田さん（Area Director）`、`佐藤さん（キャンセル）` |
| 役割表 | Role / Name / Confirmation / Contents / Time / Award。Name 欄はプルダウンの選択値で、`山田 太郎さん（ ○ ）` のように出欠マークが付く。括弧部分は取り除く |
| スピーチの Contents 欄 | 左がプロジェクト情報（3 行：パス名 / `L3 知識を増やす` のようなレベル / プロジェクト名）、右がスピーチタイトル。新しい形式では左に時限 `（4分から6分）` と説明ページへのリンクが付く。両方の形式に対応する |
| 出欠表「Alphabetical Order あいうえお順」 | 氏名 + 出欠マーク（`◎日本語` / `◎英語` / `◎日英` / `○` / `△` / `×` / 空欄）。末尾のダミー行「アサインなし さん」は除外 |
| Upcoming | 今後 5 回分の例会の日付・回数・リンク（リンク内に mtgid） |

役割名（固定）：

- 日本語セッション：今夜のトーストマスター、今夜の言葉（日英）、計時係、集計係、文法係、えーとカウンター、笑いカウンター、例会報告係、準備スピーチ1〜3、テーブルトピックスマスター、テーブルトピックス回答者1〜4、総合論評、論評1〜2
- 英語セッション：Toastmaster of the Evening、Prepared Speech1〜3、Table Topics Master、Table Topics Speaker1〜4、General Evaluation、Evaluation1〜3
- ヘルパー役（計時係など）と今夜の言葉は例会全体で 1 組だけで、両セッション共通。
- 英語セッションの担当者も、画面表示（プルダウンの選択値）の日本語名を使う。隠し項目にあるローマ字名は使わない。

**JE / EJ の判定**：役割表の先頭行が「今夜のトーストマスター」なら JE（日本語セッションが先）、「Toastmaster of the Evening」なら EJ。

**対象回の判定**：Upcoming 表から「日付が今日以降」の最初の回。回帰テスト用に mtgid の直接指定もできるようにする。

### 3.2 Pathways プロジェクト一覧（Google スプレッドシート、公開）

- `https://docs.google.com/spreadsheets/d/1ku8Aspg64CnHnyuFV3JD-d_3APnX56VxT_Z2pM3OEMw/edit?gid=827204203`
- `export?format=csv&gid=827204203` で CSV を取得できる。
- 主な列：A = プロジェクト番号、B = Level、C = 英語プロジェクト名、D = 日本語プロジェクト名。「説明資料(英)」「説明資料(日)」列はプロジェクト説明 PDF（Google Drive、公開）。
- ここから `config/projects.json`（プロジェクト名 → `{code, level, name_ja, name_en, desc_ja, desc_en}`）を作る。desc は説明 PDF の冒頭の説明文（Purpose / Overview / This project includes の部分）。
- 開発者が一度だけ生成して同梱する。毎回の実行には含めない。

## 4. テンプレート `template.xlsx`

シートは JE、EJ、プロジェクト目標 の 3 つ。JE と EJ は日英の順序が逆なだけで、セル番地は同じ。

- 印刷設定：A4 縦、1 ページに収める。印刷範囲は JE / EJ が `A1:O95`、プロジェクト目標が `B2:C8`。
- PDF には、その回で使うセッションのシート（JE か EJ）とプロジェクト目標を含める。xlsx は使わないシートも削除せずに残す。
- B 列は開始時刻。`=上の行のB+上の行のC` の連鎖（B5、B7 は固定値）。**B 列は変更しない。**
- C 列は所要時間（Excel の時刻値）。

### 4.1 セル対応表（JE / EJ 共通）

「前半」「後半」はセッションの順番を指す。JE なら前半が日本語、EJ なら前半が英語。

| 項目 | セル | 備考 |
|---|---|---|

| 日時 | J2 | `10/01 19:15～21:15`（文字列書式） |

| 前半 TMOE | J10 | |
| 今夜の言葉 | J11 | F11 の括弧（言葉そのもの）は空欄のまま |
| ヘルパー 6 役 | J13〜J18 | 計時、えーと、笑い、文法、集計、報告の順（EJ も同じ順） |

## 5. 記入ルール

### 5.1 ヘッダー

- 回数：`第384回`
- 日時：`10/01 19:15～21:15`（月日は 2 桁）
- 場所：`config/zoom.txt`（Zoom の URL・ID・パスコード。リポジトリには含めない）の内容に続けて、会場行を `config/venues.json` から入れる。
  - 角筈地域センター → `会場：角筈地域センター7F 会議室  https://tsunohazucc.com/tsunohazu_map.html`
  - 四谷地域センター → `会場：四谷地域センター 集会室３  http://ycc.tokyo/about.html`

### 5.2 役割

- Assignment 欄（TMOE、ヘルパー、スピーカー、論評、TT マスター、総合論評）は**「さん」を付けない**。氏名はページの表記どおり（姓名間の空白も残す）。
- 前半の TMOE は J10、後半の TMOE は後半セッション見出し行の J43 に `TMOE: 氏名`。
- 今夜の言葉：担当者名のみ記入。括弧内の言葉は空欄（当日発表）。
- テーブルトピックス回答者は記入しない（当日指名）。
- ページで空欄の役割は Excel でも空欄のまま。エラーにしない。

### 5.3 スピーチ

- 日本語タイトル：`『題目』（5～7分）`、英語タイトル：`"Title" (5-7 min)`。
- 時限：Contents 欄に `（4分から6分）` などがあればそれを使う（日本語は `（4～6分）`、英語は `(4-6 min)`）。なければ 5〜7 分。
- プロジェクト行：`パス名 Lx：プロジェクト名`（レベル名は書かない）。日本語は全角コロン `プレゼンテーション熟達 L3：ボーカルバラエティについて`、英語は `Motivational Strategies L3: Researching and Presenting`。
- プロジェクト目標シート：プロジェクト名で `config/projects.json` を引き、見出し `L3: プロジェクト名` と説明文（日本語スピーチは desc_ja、英語は desc_en）を記入。見つからなければ見出しのみ記入し、ログに警告。同じプロジェクトが複数ある場合は 1 回だけ載せる。並び順はプログラムに出てくる順。

### 5.4 C 列の所要時間

- スピーチ：スピーカーがいれば「時限の上限 + 1 分」（5〜7 分 → 0:08、4〜6 分 → 0:07）。いなければ 0:00。
- コメントタイム：スピーカーがいれば 0:01、いなければ 0:00。
- 論評：担当者がいれば 0:05、いなければ 0:00。
- 上記以外の行はテンプレートの値のまま。

### 5.5 スピーチが 3 本の回

1 セッションに 3 本目のスピーチがある場合（年に 2〜3 回）、2 本目のブロックの後に同じ構造のブロック（見出し行 + タイトル行 + プロジェクト行 + コメントタイム行）を挿入し、論評にも 3 行目を挿入する。Excel COM の Rows.Insert と書式・数式のコピーで行い、B 列の数式の連鎖を切らない。右側のゲスト・会員欄も行ごと下がるので、**行の挿入を先に行い、右欄はその後に記入する**。

### 5.6 右側の欄

- ゲスト：Guests 表の 1 行につき 1 人。（キャンセル）を含む行は除外。表記はページどおり（さんと括弧書きを含む）。
- 出席予定会員：あいうえお順の表で ◎（言語を問わない）または ○ の人。△・×・空欄は含めない。ページの順で、さん付き、氏名は表記どおり。
- □ は記入した行にだけ付ける（足りなければ追加し、余った □ は消す）。

### 5.7 今後の予定

Upcoming 表の、対象回を除いた最初の 2 件。形式は `11/05　木曜日　第386回例会`（曜日は日付から計算、会場は書かない）。

### 5.8 出力ファイル

`output/新宿BTMC第386回例会プログラム20261105.pdf` と、手直し用の同名 `.xlsx`。

## 6. 構成

| ファイル | 役割 |
|---|---|
| `parse.ps1` | HTML → `meeting.json`。HTMLFile COM で解析。オフラインでテスト可能 |
| `fetch.ps1`（予定） | `chrome --headless --dump-dom` で TOP と例会詳細を取得し `cache/` に保存。`-MtgId`、`-FromHtml` オプション |
| `fill.ps1`（予定） | Excel COM でテンプレートのコピーに記入し、必要なら行を挿入し、`ExportAsFixedFormat` で PDF 出力 |
| `run.bat`（予定） | 一括実行。Windows タスクスケジューラでの定期実行（隔週木曜 12:00）の設定方法も README に書く |
| `config/` | `venues.json`、`durations.json`、`projects.json`、`zoom.txt`（非公開） |
| `tests/` | Pester テストと匿名化済みフィクスチャ |
| `logs/` | 実行ログ。実行後、コンソールに「どの回を作ったか・出力先・警告の有無」を 1 行で表示 |

メール送信は今回は対象外（後から追加できるようにしておく）。

### meeting.json の形式

```json
{
  "mtgid": 257, "date": "2026/10/01", "number": 384,
  "venue": "四谷地域センター", "room": "集会室３", "format": "JE",
  "guests": ["林さん（Area Director）"],
  "roles": { "今夜のトーストマスター": "青木 一郎", "論評2": "" },
  "speeches": {
    "ja": [{ "slot": 1, "speaker": "久保さくら", "path": "プレゼンテーション熟達",
             "level": "L3", "level_name": "知識を増やす", "project": "ボーカルバラエティについて",
             "time_limit": null, "title": "…" }],
    "en": []
  },
  "attendance": [{ "name": "江口次郎さん", "mark": "○" }],
  "upcoming": [{ "date": "2026/11/05", "number": 386, "mtgid": 259 }]
}
```

- roles の氏名は「さん」なし、attendance の氏名は「さん」付き。
- キャンセルのゲストも guests に残し、除外は記入時に行う。
- `time_limit` は `{ "min": 4, "max": 6 }` または `null`。
